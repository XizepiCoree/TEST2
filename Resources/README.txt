Свои картинки для интерфейса (необязательно)
============================================

Если положить сюда PNG-файлы с такими именами, плагин возьмёт их вместо
нарисованных по умолчанию. Всё, что не положено, остаётся стандартным.

Фоны (лучше размером 1000 x 700, любые пропорции растянутся на всё окно).
Фон меняется плавно, когда вы выбираете стиль (Character) в плагине:

  scene1.png   Character: Custom
  scene2.png   Character: Sky Punch
  scene3.png   Character: Hard Stomp
  scene4.png   Character: Rawstyle
  scene5.png   Character: Rumble Wall
  scene6.png   Character: Pitch Bender
  scene7.png   Character: Crushed 96
  scene8.png   Character: Rusty Cannon
  scene9.png   Character: Short Click

Спрайт персонажа (прозрачный PNG, лучше вертикальный, примерно 420 x 700):

  heroine.png

Важно: имена файлов строго такие, маленькими буквами, формат только PNG.
Используйте только те картинки, на которые у вас есть права.
После добавления файлов заново загрузите папку на GitHub и дождитесь сборки.
